## 📌 نظرة عامة على المنظومة
منظومة رقمية متكاملة مصممة خصيصاً لإدارة ومتابعة خدمة وسائل الإيضاح بأسرة الأنبا أرسانيوس والقديس نيقولاوس. ترتكز المنظومة على السلاسة والسرعة وسهولة الاستخدام مع توفير إحصائيات بصرية دقيقة وتوثيق فوري لجميع فعاليات الخدمة.

## 🌟 الميزات والمواصفات الرئيسية الحالية

### 1. توحيد المنظومة ورتبة الخدمة
- **توحيد الخدام:** جميع أفراد المنظومة موحدون برتبة **خادم ✝️**؛ لا يوجد أي فصل بين خادم ومخدوم.
- **دخول مباشر وسلس:** فتح فوري لكافة أقسام النظام وإمكانات التسجيل دون بوابات دخول معقدة أو كلمات سر تعيق العمل الميداني السريع.

### 2. أنواع الأيام وتسجيل الحضور والغياب
عند تسجيل أو تعديل أي يوم حضور، تتيح المنظومة تحديد **نوع اليوم 🏷️** بدقة:
1. **اجتماع 📖:** للاجتماعات الروحية والدراسية والتحضيرية.
2. **شغل 🛠️:** لورش العمل وفرز وصيانة خامات وأدوات وسائل الإيضاح.
3. **اجتماع وشغل 📖🛠️:** للأيام الجامعة بين الاجتماع والنشاط العملي والورش.

**حالات التسجيل في كل يوم:**
- **حاضر 🟢:** الحضور الفعلي للجلسة أو الورشة.
- **غياب بعذر 🟡:** غياب مسجل ومقبول بإذن مسبق (يُحسب إيجابياً في صافي الالتزام بالعذر).
- **غياب بدون عذر 🔴:** غياب غير مبرر يخفض نسبة الالتزام ويظهر تنبيهاً للافتقاد.

### 3. شريط الجزيرة التفاعلية العائمة (Dynamic Island)
- **مظهر عصري منبثق (Glowing Pop-up):**
  - عند التمرير لأسفل (Scroll)، يختفي الهيدر الكبير تلقائياً وتظهر الجزيرة التفاعلية كشريط علوي عائم مدمج بسطر واحد مع تأثير وهج راقٍ ومعدل إطارات سلس (60fps).
  - عند الرجوع لأعلى الصفحة، يختفي الشريط بسلاسة ويعود الهيدر الرئيسي للظهور.
- **مكونات الجزيرة التفاعلية (سطر واحد منظم):**
  - **شعار الخدمة** التفاعلي.
  - **نبض ضوئي ذكي (Pulse):** أخضر عند اكتمال تسجيل جميع الأيام، وأصفر نابض عند وجود أيام فائتة معلقة.
  - **بادج الأيام المعلقة:** يوضح عدد الأيام التي تحتاج تسجيل ويفتح كشف الغياب مباشرة بنقرة واحدة.
  - **مؤشر الالتزام العام:** النسبة المئوية لمتوسط حضور الخدمة لحظياً.
  - **إجمالي الخدام:** عدد الخدام المسجلين بالنظام.
  - **بحث سريع:** زر يركز شريط البحث فوراً للوصول لأي خادم بالاسم.
  - **نسخ جدول الخطة:** نسخ فوري لنص جدول الخطة ومواعيدها إلى الحافظة 📋.
  - **زر العودة للأعلى:** للرجوع السريع لأعلى الصفحة وإظهار الواجهة الرئيسية.

### 4. إدارة الخطة الأسبوعية والاستدراك التلقائي
- **عرض نص وتفاصيل الخطة:** واجهة مميزة لعرض جدول المواعيد والموضوعات مع إمكانية التعديل السريع.
- **مستخرج الأيام الذكي:** استخراج تلقائي لتواريخ وأيام الخطة من النصوص المكتوبة وترتيبها.
- **استدراك الأيام الفائتة:** بانر ذكي ينبه أمين الخدمة بالأيام المجدولة التي انتهى تاريخها دون تسجيل غيابها، مع زر للتسجيل الفوري.
- **إضافة يوم إضافي (خارج الخطة):** نافذة لإضافة ورش عمل طارئة أو مواعيد غير مجدولة مع تحديد نوع اليوم وربطه التلقائي بالأحداث.

### 5. خصوصية كاملة وخلو من أي أرقام هواتف
- تم تطهير المنظومة بالكامل من أي حقول لهواتف أو واتساب أو وسائل اتصال خارجية بناءً على التوجيهات؛ يعتمد النظام بالكامل على اسم الخادم والمتابعة الشخصية والافتقاد الكنسي المباشر.

### 6. التحليلات والرسوم البيانية المتقدمة (Chart.js)
لكل خادم بطاقة خاصة تتضمن:
- نسبة الالتزام الصافي بالمعادلة: `(حاضر + معتذر) ÷ إجمالي الجلسات`.
- عدد مرات النزول في الأحداث وحساب الـ **Overload ⚡** (الحضور الإضافي الذي يزيد عن الهدف المطلوب للموسم).
- **نافذة التحليلات البصرية الشاملة لكل خادم:**
  - رسم بياني دائري (Doughnut) لتوزيع الحضور والاعتذار والغياب.
  - رسم بياني بالأعمدة (Bar Chart) لالتزام الأحداث ومعدلات الـ Overload.
  - رسم بياني لحالات المهام الموكلة للخادم.
  - خط زمني تفاعلي (Timeline) يوضح التزام الخادم عبر الشهور.

### 7. إدارة وتكليف المهام
- إضافة وتعديل المهام وتعيينها لواحد أو أكثر من الخدام.
- تحديث حالات المهام (قيد الانتظار ⏳، قيد التنفيذ ⚙️، منجزة ✅، لم تُنجز ❌).
- متابعة نسبة إنجاز المهام على مستوى الخادم وعلى مستوى الخدمة ككل.

### 8. إدارة الأحداث والمواسم (Events & Seasons)
- إنشاء فعاليات كنسية ومواسم (مثل: تجهيز المعارض، أسبوع الآلام، الكريسماس، نهضات الأعياد).
- تحديد الحد المستهدف لنزول كل خادم، واحتساب أي نزول إضافي تلقائياً كـ **Overload ⚡** لتكريم الأكثر نشاطاً.

### 9. مركز التقاير والتصدير والطباعة
- **تصدير إكسيل (CSV):** بضغطة زر واحدة متوافق مع كافة برامج الجداول الإلكترونية.
- **معاينة وطباعة (Print / PDF):** استخراج كشوفات حضور منسقة رسمياً وجاهزة للطباعة والتوقيع وتقديمها للآباء الكهنة وأمانة الخدمة.

## 🛠️ البنية التقنية (Tech Stack)
- **الخادم الخلفي (Backend):** Node.js و Express.js مع تخزين محلي منظم في `data.json` ومسارات API RESTful سريعة.
- **الواجهة الأمامية (Frontend):** Modern Vanilla JavaScript و HTML5 و Tailwind CSS مع وضع ليلي/نهاري مريح للعين ودعم كامل للغة العربية (RTL).
- **المكتبات الرسومية:** Chart.js لإنشاء المخططات والرسوم البيانية التفاعلية.
- **الهيكلية البرمجية المقسمة (Modular ES6 Architecture):**
  - `js/store.js`: المخزن التفاعلي المركزي لحالة المنظومة وإدارة البيانات والمعادلات (State Management & Math Engine).
  - `js/ui.js`: واجهة المستخدم العامة، النوافذ المنبثقة، التنبيهات، الوضع الليلي/النهاري، والجزيرة التفاعلية (Single-Row Dynamic Island).
  - `js/plan.js`: عارض ومحرر الخطة، مستخرج المواعيد الشهري الذكي، الكشكول، واستدراك الأيام الفائتة.
  - `js/servants.js`: إدارة بطاقات الخدام، الفلترة، البحث الفوري (80ms Debounce + rAF)، وكشوف الحضور والتاريخ.
  - `js/analytics.js`: الرسوم البيانية التفاعلية للخدام عبر Chart.js مع إدارة دورة حياة الذاكرة والتدمير النظيف.
  - `js/tasks-events.js`: تكليف ومتابعة المهام، مواسم وأحداث الخدمة مع حساب الـ Overload ⚡، ومركز التصدير (CSV / PDF / Print).
  - `app.js`: الملف الرئيسي المنسق العام (Master Orchestrator) والتفويض الموحد للأحداث (Event Delegation).
- **التصميم التفاعلي والأداء الفائق:**
  - Dynamic Island خفيفة بدون أي بطء أو تجميد للشاشة بمعدل 60fps مع التمرير السلس.
  - تحسين سرعة الاستجابة اللحظية (INP) عبر تجزئة DOM المجمعة (`DocumentFragment`) والمزامنة التفاؤلية الفورية (Optimistic UI).
  - بحث لحظي بالاسم مدعوم بـ Debounce بقيمة 80ms مع معالجة غير متزامنة للصور والتحديثات.
  - إدارة نظيفة للذاكرة ومنع تسريب مخططات Chart.js عبر التدمير المنظم (`.destroy()`) قبل إعادة الرسم.
  - نقطة فحص حالة الخادم والخفة الفورية عبر مسار `/api/status`.
