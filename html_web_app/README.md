# 🌐 مشروع الويب | HTML5 / JavaScript Attendance Web App
### أسرة الأنبا أرسانيوس والقديس نيقولاوس لوسائل الإيضاح

نسخة الويب الكاملة والحديثة المبنية بتصميم **Liquid Glass** الفاخر المقتبس من ألوان الشعار الكنسي الملكي، وتقنيات Tailwind CSS وJavaScript الحديثة مع الترويسة القابلة للطي وشريط البحث السريع.

---

## 📁 محتويات مجلد مشروع الويب (`html_web_app/`)

```text
html_web_app/
│
├── index.html         # الصفحة الرئيسية لواجهة المستخدم (Liquid Glass، RTL، متجاوبة)
├── app.js             # كود منطق الواجهة وإدارة الحالة والبحث والترويسة القابلة للطي
├── assets/            # مجلد الأصول والوسائط
│   └── logo.png       # شعار الأسرة ووسائل الإيضاح
├── logo.png           # الشعار المباشر
├── run_local.bat      # أداة تشغيل سريعة بضغطة زر لنظام Windows
└── README.md          # الدليل الشامل لنسخة الويب
```

---

## 🌟 الميزات الحديثة المضافة

1. **تصميم زجاجي Liquid Glass:**
   - زجاج فخم بانعكاسات ذهبية ملوكية وألوان دافئة مستوحاة من ألوان الشعار.
   - تأثيرات `backdrop-filter: blur(16px)` وظلال ناعمة وإضاءة حواف ذهبية.
2. **ترويسة ذكية وشعار يختفي عند التمرير (Collapsible Header on Scroll):**
   - الشعار في القمة يتقلص ويختفي بنعومة عند النزول لأسفل لتوفير مساحة العمل.
   - اسم الخدمة يظهر بوضوح مع شريط تحكم كامل (الوضع الليلي/النهاري، تبديل اللغة، حالة الاتصال، وحساب المسؤول).
3. **شريط بحث سريع ومباشر في بطاقات الأشخاص (`person-card-container`):**
   - بحث فوري بالاسم مع تصفية ديناميكية لحظية.
   - عداد مباشر لعدد الأشخاص المعروضين من الإجمالي وزر مسح سريع.
4. **دعم كامل للوضعين النهاري والليلي وتعدد اللغات (عربي / English).**

## ⚡ طرق التشغيل على جهازك (Windows)

### الطريقة الأولى: التشغيل التلقائي بضغطة زر (الأسهل)
- انقر نقراً مزدوجاً على ملف `run_local.bat`.
- سيقوم السكربت بتشغيل الخادم المحلي على المنفذ `3000` وفتح المتصفح فوراً على `http://localhost:3000`.

### الطريقة الثانية: التشغيل عبر موجه الأوامر (CMD)
من المجلد الرئيسي للمشروع:
```cmd
npm install
npm run dev
```
ثم افتح متصفحك على: `http://localhost:3000`

## 🔧 بنية الكود وسهولة التوسعة والصيانة (Clean Architecture & Maintainability)

1. **فصل واجهة العرض والمنطق (Separation of Concerns)**:
   - تم تصميم `index.html` ليكون نظيفاً ومقسماً إلى أقسام دلالية واضحة.
2. **المنطق البرمجي في `app.js`**:
   - إدارة حالة موحدة للبيانات (`state`).
   - دوال معيارية لحساب معدلات الحضور والـ Overload.
   - تشفير وعرض آمن لتجنب ثغرات حقن النصوص البرمجية.
