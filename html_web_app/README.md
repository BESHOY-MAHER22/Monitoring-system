# 🌐 مشروع الويب | HTML5 / JavaScript Attendance Web App
### أسرة الأنبا أرسانيوس والقديس نيقولاوس لوسائل الإيضاح

نسخة الويب الكاملة المبنية باستخدام HTML5 الحديث، تقنيات Tailwind CSS، وJavaScript التفاعلية، وتعمل بسلاسة على كافة متصفحات الويب وأجهزة الجوال والكمبيوتر.

---

## 📁 محتويات مجلد مشروع الويب (`html_web_app/`)

```text
html_web_app/
│
├── index.html         # الصفحة الرئيسية لواجهة المستخدم (RTL، متجاوبة مع كافة الشاشات)
├── app.js             # كود منطق الواجهة وإدارة الحالة والاتصال بالخادم
├── data.json          # قاعدة بيانات الأشخاص وسجلات الحضور والمهام
├── assets/            # مجلد الأصول والوسائط
│   └── logo.png       # شعار الأسرة ووسائل الإيضاح
├── run_local.bat      # أداة تشغيل سريعة بضغطة زر لنظام Windows
└── README.md          # الدليل الشامل لنسخة الويب
```

---

## ⚡ طرق التشغيل على جهازك (Windows)

### الطريقة الأولى: التشغيل التلقائي بضغطة زر (الأسهل)
- انقر نقراً مزدوجاً على ملف `run_local.bat`.
- سيقوم السكربت بتشغيل الخادم المحلي على المنفذ `3000` وفتح المتصفح فوراً على `http://localhost:3000`.

### الطريقة الثانية: التشغيل عبر موجه الأوامر (CMD):
من المجلد الرئيسي للمشروع:
```cmd
npm install
npm run dev
```
ثم افتح متصفحك على: `http://localhost:3000`

### الطريقة الثالثة: فتح الملف مباشرة في المتصفح
- يمكنك فتح `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح، وستعمل الواجهة بكامل مميزاتها التفاعلية.

## 🔧 بنية الكود وسهولة التوسعة والصيانة (Clean Architecture & Maintainability)

1. **فصل واجهة العرض والمنطق (Separation of Concerns)**:
   - تم تصميم `index.html` ليكون نظيفاً ومقسماً إلى أقسام دلالية:
     - شريط التنقل العلوي والمؤشرات التنفيذية (KPI Cards).
     - جدول تسجيل الحضور السريع والبحث الفوري.
     - قسم حلول أسئلة الإدارة (الأكثر غياباً، الافتقاد، لوحة الشرف، الـ Overload).
     - إدارة المهام وتوزيع المسؤوليات.
     - النوافذ المنبثقة للتقارير والتصدير (CSV / PDF / Print).
2. **المنطق البرمجي في `app.js`**:
   - إدارة حالة موحدة للبيانات (`state`).
   - دوال مساعدة معيارية لحساب معدلات الحضور والـ Overload.
   - تشفير وعرض آمن لتجنب ثغرات حقن النصوص البرمجية (XSS Protection).
